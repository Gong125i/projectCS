# System Flow Diagram - ระบบจัดการนัดหมาย

## 📋 ภาพรวมระบบ

ระบบจัดการนัดหมายสำหรับนักศึกษาและอาจารย์ที่ปรึกษา เพื่อจัดการการนัดหมาย โปรเจค และการแจ้งเตือน

---

## 🎯 Main System Flow

### **1. User Authentication Flow**

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           USER AUTHENTICATION FLOW                             │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  [Login Page] ──→ [Enter Credentials] ──→ [Validate User] ──→ [Check Role]     │
│       │                    │                     │                    │         │
│       │                    │                     │                    │         │
│       │                    │                     │                    ▼         │
│       │                    │                     │              ┌─────────────┐ │
│       │                    │                     │              │   Student   │ │
│       │                    │                     │              │  Dashboard  │ │
│       │                    │                     │              └─────────────┘ │
│       │                    │                     │                    │         │
│       │                    │                     │                    ▼         │
│       │                    │                     │              ┌─────────────┐ │
│       │                    │                     │              │   Advisor   │ │
│       │                    │                     │              │  Dashboard  │ │
│       │                    │                     │              └─────────────┘ │
│       │                    │                     │                              │
│       │                    │                     └── [Invalid Credentials] ──→  │
│       │                    └── [Validation Error] ──→ [Show Error Message]      │
│       └── [Cancel] ──→ [Return to Login]                                          │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

**คำอธิบาย Authentication Flow:**
1. ผู้ใช้เข้าสู่ระบบผ่านหน้า Login
2. ระบบตรวจสอบข้อมูลผู้ใช้ (phone, password)
3. ตรวจสอบบทบาท (student/advisor)
4. นำทางไปยัง Dashboard ตามบทบาท
5. หากข้อมูลไม่ถูกต้อง แสดงข้อความ error
